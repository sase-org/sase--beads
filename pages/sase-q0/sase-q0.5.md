## Description

The sase-github plugin acquires workspaces the same way the rest of SASE does: every gh__setup and GitHub-submit allocation is a single atomic claim whose result is checked and whose ledger record names its caller, a pinned n=<num> target that a live agent holds fails with that agent named instead of being taken, and no gh workflow step stashes, pulls, or checks out inside a checkout another live agent occupies.
